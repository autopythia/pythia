# Errors in glem programs, from glem's rewrite or from lem's checker after
# it, each a case: `=== title`, the source of t.lem, which loads after
# glem's prelude, `---`, then the error, as lem shows it.

=== Text where a widget's message goes, as in the design
id Top, Go
msg Run
surface Screen(title: Text)
widget Press(text: Text, on: Msg)
Screen(Top, title="Tasks"):
  Press(Go, text="Run now", on="go")
---
t.lem:6:32: Press's `on` is a Msg, but this is a Text:
  Press(Go, text="Run now", on="go")
                               ^^^^

=== a widget outside any block
id W
widget Line(text: Text)
Line(W, text="hi")
---
t.lem:3:1: Line needs a `parent`: put it in a widget's block, or give `parent=`:
Line(W, text="hi")
^^^^

=== a block under a relation
rel X(c: Text)
X("a"):
  X("b")
---
t.lem:2:1: only a widget or a surface has a block of what's inside it:
X("a"):
^^^^^^

=== a surface in a block
id Top, Inner
surface Screen(title: Text)
Screen(Top, title="a"):
  Screen(Inner, title="b")
---
t.lem:4:3: Screen is a surface, so it can't be inside a block:
  Screen(Inner, title="b")
  ^^^^^^
