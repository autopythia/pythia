# The approval HUD (approval.lem, with host.lem) through glui's recipes
# (src/glui/glui.js) in a stand-in DOM, for the tests in JavaScript alone
# (tools/glui_test.js). Each case runs on what the cases before it left,
# from no facts: `=== title`; lines of JSON: the host's steps
# (src/lem/host.rs), which the view runs as one tick, and what a user does
# to a widget, named by its id as lem writes it:
#
# - `["click", widget]`: a click on its element;
# - `["check", widget]`: its checkbox, checked or unchecked;
# - `["type", widget, text]`: text typed into its field;
# - `["compose", widget, text]`, `["composed", widget]`: text from an input
#   method while it composes, and the composition's end;
# - `["open", widget]`, `["close", widget]`: its entry, opened or closed;
# - `["focus", widget]`, `["blur"]`: the keyboard's focus on its control,
#   if it has one, else its element; or away;
# - `["key", name]`, `["key", name, modifiers]`: a key, as the DOM names
#   it, pressed where the focus is, or on the view's root;
#
# then `---`; then the page's title, if it has one; the page, an element a
# line: its tag and classes, its other attributes, an input's state
# (`:checked`, `:value`) and its text, with what it holds under it; the
# Focused fact, if any; and what the host heard: each effect, by its name
# and its fields as JSON, and each error.
