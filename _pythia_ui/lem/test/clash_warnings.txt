# Programs whose keys the checker checks before a tick runs
# (src/lem/clash.rs): each case's lines, loaded as `t.lem` after lem's
# prelude; then the warnings that it gives, or (none).

=== a key that fixes the rest of the fact
input Todo(id: Text, title: Text) key id
rel Shown(id: Text, title: Text) key id
Shown(i, t) :- Todo(i, t)
---
(none)

=== a key that doesn't fix a column
input Todo(id: Text, title: Text, tag: Text)
rel Shown(id: Text, title: Text) key id
Shown(i, t) :- Todo(i, t, _)
---
t.lem:3:1: warning: this rule may give Shown two facts with one key, which differ in `title`:

=== a key computed by arithmetic, which fixes nothing
